# Тема WordPress «Культура Неона» — этап 1

Тема основана на существующих утверждённых HTML-страницах из корня репозитория.

## Установка
1. Скопируйте папку `wordpress-theme/kultura-neona` в `wp-content/themes/kultura-neona` или упакуйте только содержимое этой папки в ZIP и загрузите через Внешний вид → Темы → Добавить → Загрузить тему.
2. Активируйте тему. Она создаст страницы для каталога и моделей, если их нет.
3. Настройки → Чтение → «Статическая страница» — выбрать главную страницу, либо WordPress автоматически использует `front-page.php` на корне.
4. Настройки → Постоянные ссылки → «Название записи», затем сохранить.

## Важно
- На первом этапе сохранена HTML-верстка. Каталог и цены пока статические, а кнопки заказа копируют заявку, **не оформляют заказ WooCommerce**.
- Картинки временно загружаются с опубликованного GitHub Pages `https://ravezox.github.io/kultura-neona/`; не удаляйте репозиторий или исходные файлы.
- Для настоящего магазина следующим этапом надо сделать динамические шаблоны WooCommerce, импортировать товары и заменить кнопки заказа.
- Перед активацией на рабочем сайте проверьте тему на тестовом экземпляре WordPress.
